# bank-personal-loan-analysis
Bank Personal Loan Analysis using Python, SQL and Power BI

## 📌 Project Overview
This project analyzes customer data to understand personal loan acceptance patterns and customer characteristics.

## 🛠️ Tools Used
- Python — data cleaning and exploratory data analysis
- SQL — data querying and analysis
- Power BI — interactive dashboard and visualization

## 📊 Dashboard Highlights
- Total Customers: 5,000
- Loan Accepted: 480
- Loan Rejected: 4,520
- Average Income: 73.77 (dataset units)

## 📈 Key Features
- Loan acceptance and rejection distribution
- Customer distribution by education
- Average income by education
- Loan status comparison by education
- Interactive filters for age, education, family, and loan status
